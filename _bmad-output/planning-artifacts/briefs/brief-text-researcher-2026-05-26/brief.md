# Product Brief: text-researcher

## Executive Summary

text-researcher — это TUI-приложение для глубокого лингвистического анализа текста. Работает в терминале в полноэкранном режиме. Исследователь загружает текст (из файла или вставкой), перемещает курсор по словам и моментально видит в соседней панели полную морфологическую картину выделенного слова: часть речи, род, число, падеж, время, лицо и другие признаки.

Это не блокнот и не словарь. Это исследовательский инструмент для тех, кому нужно не просто прочитать текст, а препарировать его — слово за словом. Первичная аудитория: лингвисты, филологи, переводчики, студенты языковых специальностей.

Технически — Rust + Ratatui (TUI) + UDPipe (морфологический анализ). Проект личный, но с инженерной культурой: Make, Docker, CI/CD.

## The Problem

Существующие инструменты морфологического анализа (веб-сервисы, Python-скрипты, IDE-плагины) неудобны для глубокой работы с текстом. Исследователю приходится:
- Копировать слово в веб-форму, получать результат, возвращаться к тексту — постоянное переключение контекста
- Работать в нетерминальных средах, когда весь остальной инструментарий — в терминале
- Мириться с тем, что анализатор выдаёт результат один раз и не обновляется при перемещении по тексту

Терминальный, клавиатурно-управляемый инструмент, который показывает морфологию «на лету» при движении курсора — такого нет.

## The Solution

Полноэкранное TUI-приложение с двумя (в перспективе — тремя и более) панелями:

- **Основная панель:** текст, загруженный из файла или вставленный. Курсор ходит по словам (клавишами или vim-подобно). Подсветка текущего слова.
- **Панель свойств:** морфологические признаки выделенного слова — часть речи, лемма, род, число, падеж, время, лицо, наклонение и т.д. Обновляется мгновенно при перемещении курсора.
- **Строка меню и статус-строка:** навигация, загрузка файла, информация о текущем документе.

Морфологический движок — UDPipe 2 через Rust-обёртку `udpipe-rs`. Поддержка 100+ языков через подключаемые модели Universal Dependencies. Стартовые языки: русский, английский.

## What Makes This Different

- **Клавиатурная эффективность.** Курсор движется — анализ обновляется. Без мыши, без веб-форм, без переключения окон.
- **Богатый набор клавиатурных шорткатов.** Быстрые действия со словами: копирование леммы, переключение языков анализа, переход к следующему слову той же части речи, добавление в пользовательский словарь — всё с клавиатуры, без отрыва от текста.
- **Терминал-first.** Там же, где vim, git, grep и всё остальное. Для пользователей, чья среда — CLI.
- **Настоящая морфология.** Не просто «существительное», а полный набор признаков из академического пайплайна UDPipe/Universal Dependencies.
- **Архитектура под рост.** Два окна сегодня → окно связей (dependency parsing) завтра → словари, классификаторы, диалоги добавления слов — без переписывания с нуля.

## Who This Serves

**Первичный пользователь:** лингвист-исследователь, филолог, переводчик. Человек, который работает с текстом на уровне структуры языка. Ему важно быстро получить морфологический разбор и не отвлекаться на интерфейс.

**Вторичный:** студент языковых специальностей, изучающий морфологию на реальных текстах. [ASSUMPTION]

## Success Criteria

- Пользователь загружает текст из файла и видит его в основной панели за время < O(размер файла в строках)
- При навигации курсором по словам панель свойств обновляется мгновенно (субъективно без задержки)
- Морфологический разбор точен в рамках моделей UDPipe для русского и английского языков
- Приложение собирается одной командой (`make build`) и запускается в Docker одной командой
- Код читаем junior-разработчиком Rust [ASSUMPTION: количественная метрика — ни один файл > 300 строк без веской причины]

## Scope

**MVP (v1):**
- Загрузка текста из файла (.txt) и вставка через буфер
- Двухпанельный интерфейс: текст + свойства слова
- Навигация по словам (стрелки / vim-подобные клавиши)
- Морфологический анализ через UDPipe (русский, английский)
- Меню и статус-строка
- Сборка через Make, упаковка в Docker, CI/CD

**За рамками MVP (v2+):**
- Панель связей слов (dependency parsing)
- Диалоги добавления слов в пользовательский словарь
- Присвоение слов классификаторам
- Интеграция с Национальным корпусом русского языка (офлайн-дамп в `lib/`)
- Поддержка дополнительных языков

**Явно исключено:**
- Графический интерфейс (GUI)
- Редактирование текста — только просмотр и анализ
- Веб-интерфейс
- Коллаборативная работа

## Vision

Если проект приживётся — text-researcher станет стандартным инструментом лингвиста в терминале, как vim для разработчика. Расширяемая архитектура позволит добавлять окна под разные аналитические задачи: частотный словарь, поиск по шаблонам (regexp по морфологическим признакам), сравнительный анализ двух текстов бок о бок. Интеграция с корпусами текстов сделает возможным анализ не только отдельного документа, но и больших массивов языкового материала — всё внутри одной TUI-среды.
