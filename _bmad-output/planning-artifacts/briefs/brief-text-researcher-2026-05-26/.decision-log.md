# Decision Log

## 2026-05-26

### Language choice: Crystal → Rust
- **Initial:** V → Crystal
- **Final:** Rust
- **Why:** Crystal TUI ecosystem too thin (Keimeno — basic, crt.cr — abandoned). Rust + Ratatui is mature, production-grade.
- **User directive:** "пиши на rust без изысков, чтобы и junior-у было понятно"

### TUI framework: Ratatui
- Ratatui is the standard TUI framework for Rust (community fork of tui-rs)
- Supports multiple panes, layouts, cursor handling out of the box

### Morphological engine: UDPipe 2 via udpipe-rs
- Multi-language (100+ languages via Universal Dependencies models)
- C++ library with Rust bindings
- Provides: tokenization, POS tagging, lemmatization, morphological features, dependency parsing
- Academic standard, actively maintained (last release Nov 2023)
